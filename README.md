# 🎨 AI Image Colorization Frontend

A modern React-based web interface for an AI-powered image colorization system using deep learning models (U-Net + cGAN).

---

## 🚀 Project Overview

This frontend allows users to:

- Upload grayscale images
- Send images to backend AI model API
- View colorized results in real time
- Compare outputs from different models

---

## 🧠 Backend Integration

This frontend connects to an AI backend that uses:

- U-Net model (fast, stable results)
- Conditional GAN (cGAN) model (high realism)

---

## ⚙️ Tech Stack

- React.js
- JavaScript (ES6+)
- Axios (API calls)
- HTML5 / CSS3
- Vite (build tool)

---

## 🎯 Features

- 📤 Image upload interface
- ⚡ Real-time API communication
- 🖼 Before / After image preview
- 🔁 Model switching support (U-Net / cGAN)
- 📱 Responsive UI design
